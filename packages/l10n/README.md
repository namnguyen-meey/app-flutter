# l10n

> Tầng 2 · Nền tảng · Flutter package

Đa ngôn ngữ (tiếng Việt, tiếng Anh) dùng **slang**:

- File dịch `vi` và `en`, code truy cập chuỗi được sinh tự động, an toàn kiểu.
- Extension chuyển `Failure` thành câu thông báo theo ngôn ngữ đang chọn.
  Nhờ vậy mọi màn hình hiển thị lỗi theo một cách thống nhất.

| | |
|---|---|
| **Phụ thuộc vào** | `shared_domain` (để biết các loại `Failure`) |
| **Được dùng bởi** | mọi `feature_*`, `main_app`, `widgetbook_app` |
